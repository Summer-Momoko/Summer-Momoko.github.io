# Ray Lu personal site

Static Jekyll portfolio for GitHub Pages at `summer-momoko.github.io`.

## Project constraints

- Keep the complete website at the repository root for GitHub Pages branch `main`, folder `/` (root).
- Use Markdown pages with YAML front matter, shared Jekyll layouts/includes, and plain HTML/CSS.
- Do not add a backend, database, separate application, `package.json`, or framework.
- Do not invent biography, accomplishments, projects, clients, metrics, or employers.
- Keep the About copy marked as a placeholder until Ray supplies it; contact links only to LinkedIn.

## Source map

- `_config.yml` — site URL, empty `baseurl`, navigation, and Jekyll plugins.
- `index.md`, `about.md`, `experience.md`, `contact.md` — page content.
- `_layouts/` and `_includes/` — shared semantic site structure.
- `assets/css/site.css` — responsive styling; `assets/favicon.svg` — favicon.
- `README.md` — local preview, content updates, Lighthouse, and GitHub Pages setup.
